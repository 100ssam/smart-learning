# 고등학생용 컴퓨터활용능력 2급 필기 CBT 모의고사 시스템 (정규 40문항)

본 프로젝트는 고등학생들의 컴퓨터활용능력 2급 필기 자격증 취득 및 수업용 평가를 위해 순수 HTML, CSS, JavaScript로 개발된 온라인 CBT(Computer Based Test) 모의고사 웹사이트입니다.

실제 대한상공회의소 컴퓨터활용능력 2급 필기 정규 시험과 동일하게 **1과목 컴퓨터 일반 20문항 + 2과목 스프레드시트 일반 20문항 = 총 40문항(40분)**으로 구성되어 있습니다.

React나 Vue 같은 외부 프레임워크 없이 가볍고 빠르게 구동되며, GitHub Pages를 통해 즉시 무료 배포가 가능합니다.

---

```text
exams/com2-cbt/

├── css/

├── js/
│   ├── questions.js    # 문제은행 데이터 (컴퓨터 일반 30제 + 스프레드시트 30제 = 총 60제 풀)
│   └── app.js          # 시험 로직, 40분 타이머, OMR 마킹, 새로고침 복구, 채점, 오답노트 기능
└── README.md           # 모의고사 모듈 안내 및 실행 가이드
```

## 🌟 핵심 기능 및 특징

1. **정규 40문항 실전 모의고사 (1과목 20문항 + 2과목 20문항)**
   - 1과목 컴퓨터 일반 20문항 + 2과목 스프레드시트 일반 20문항 = 총 40문항 (문항당 2.5점, 100점 만점).
   - 60문항의 교사 검증 문제은행 풀에서 과목별 20문항씩 중복 없이 무작위로 추출하여 매 시험마다 새로운 조합으로 출제됩니다.

2. **철저한 시험 공정성 (제출 전 정답 비공개)**
   - 40문항을 모두 풀고 최종 제출하기 전까지는 정답이나 해설이 절대 공개되지 않습니다.
   - 미응답 문항이 남아 있는 상태에서 제출 시도 시 경고 알림 모달을 통해 미응답 문항 수를 사전에 확인시켜 줍니다.

3. **새로고침(F5) 답안 & 시간 완벽 복원**
   - 학생이 실수로 브라우저를 닫거나 새로고침을 누르더라도, 풀던 문제 번호, 체크한 답안, 남은 시험 시간이 `localStorage`를 통해 즉시 복구되어 이어서 시험을 치를 수 있습니다.

4. **40분 카운트다운 타이머 & 자동 제출**
   - 실제 시험과 동일한 40분 제한 시간이 실시간으로 카운트다운되며, 종료 5분 전에는 붉은색 경고 표시가 나타납니다.
   - 시간이 00:00이 되면 현재까지 마킹된 답안으로 즉시 자동 제출됩니다.

5. **상세 채점 성적표 & 과목별 점수 분석**
   - 총점 및 실제 컴활 2급 필기 합격 기준(전 과목 평균 60점 이상, 과목당 40점 이상 과락 방지)에 따른 합격/불합격 판정.
   - 1과목(50점 만점, 20문항), 2과목(50점 만점, 20문항) 각각의 득점 및 정답률 게이지 제공.

6. **보기별(①~④) 오답 분석 & 심층 해설**
   - 단순 정답 해설뿐만 아니라, 오답 보기 3개가 "왜 틀렸는지"까지 개별 보기마다 명쾌하게 설명합니다.

7. **오답노트 필터링 & 정답 가린 채 오답 다시 풀기**
   - 결과 화면에서 **[틀린 문제만 모아보기]** 버튼을 통해 취약한 문항만 빠르게 복습할 수 있습니다.
   - **[틀린 문제만 다시 풀기]** 모드를 실행하면 정답과 해설이 완전히 가려진 상태에서 오답을 다시 풀어보고 즉석에서 재채점할 수 있습니다.

8. **개인정보 보호 및 무제한 재응시**
   - 학생이 입력한 성명과 학번은 일체 외부 서버로 전송되지 않으며, 사용자 브라우저 로컬 저장소에만 안전하게 보관됩니다.
   - 응시 이력(회차, 점수, 일시)이 브라우저에 누적 기록되며, 횟수 제한 없이 무제한으로 새 시험을 치를 수 있습니다.

## 🚀 실행 및 테스트 방법

### 1. 로컬 환경에서 바로 실행하기
별도의 웹 서버 설치 없이 `index.html` 파일을 더블 클릭하여 크롬, 엣지, 웨일, 사파리 등의 브라우저에서 바로 열 수 있습니다.

(또는 VS Code Live Server나 간단한 로컬 서버 실행):
```bash
# Python 내장 서버 예시
python -m http.server 8080
# 브라우저에서 http://localhost:8080 접속
```

### 2. GitHub Pages 배포 방법
1. 본 프로젝트의 파일들을 GitHub 저장소(Repository)에 업로드합니다.
2. 저장소의 `Settings` > `Pages` 메뉴로 이동합니다.
3. `Branch`를 `main` 또는 `master`로 지정하고 `/ (root)`를 선택한 뒤 `Save`를 클릭합니다.
4. 잠시 후 제공되는 GitHub Pages URL로 접속하면 어디서든 모바일, 태블릿, PC로 접속 가능합니다.
