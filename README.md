# 🎓 Smart Learning (스마트러닝) 통합 교육 웹사이트

고등학생 및 IT 자격증 수험생을 위한 오픈소스 반응형 통합 스마트 학습 플랫폼입니다.  
별도의 백엔드 서버나 복잡한 프레임워크(React, Vue 등) 없이 순수 **HTML5, CSS3, JavaScript**로 제작되어 **GitHub Pages**를 통해 즉시 무료 배포할 수 있습니다.

---

## 📁 프로젝트 폴더 구조

```text
smart-learning/
```

## 🌟 핵심 기능 및 구성

### 1. 전체 학습실 메인 허브 (`index.html`)
- **4대 학습 영역 통합 관리**:
  - 📝 **모의고사 센터**: 정규 시간 제한 CBT 및 성적 관리
  - ❓ **학습 퀴즈룸**: 단원별 집중 퀴즈 및 스피드 OX 퀴즈
  - 💻 **실습 자료실**: 노코드 웹 엑셀 실습 및 HTML/CSS 라이브 샌드박스
  - 📚 **학습 자료실**: 고빈출 압축 요약집(PDF) 및 공식 치트시트
- **학습 상태 배지 시스템**:
  - `즉시 응시 가능`: 현재 완성된 콘텐츠로 즉시 학습 가능
  - `준비 중`: 클릭 시 제작 현황을 친절하게 안내하는 팝업 모달 제공
- **카테고리 퀵 필터**: 전체 보기 및 관심 분야별 원클릭 필터링 지원

### 2. 컴퓨터활용능력 2급 필기 정규 CBT (`exams/com2-cbt/`)
- 실제 시험과 동일한 **1과목 20문항 + 2과목 20문항 = 총 40문항 (40분)** 시험
- 60문항 검증 문제풀에서 과목별 20문항 무작위 추출 출제
- 실시간 OMR 카드 마킹 & 미응답 문항 경고 알림
- 브라우저 새로고침(F5) 시 마킹 답안 및 남은 시험 시간 즉시 복원
- 과목별 점수 분석(과락 40점 방지, 평균 60점 합격 판정)
- 4지선다 개별 보기 해설 & 오답노트 모아보기 & 정답 가린 채 오답 다시 풀기

## 🚀 GitHub Pages 배포 가이드

본 프로젝트의 모든 링크 및 에셋 경로는 **상대 경로(`href="./...", href="../..."`)**로 작성되어 있어, 저장소의 서브 디렉토리 배포 환경에서도 오류 없이 완벽하게 작동합니다.

1. 본 `smart-learning` 프로젝트 폴더의 전체 내용을 GitHub 저장소(Repository)에 커밋 및 푸시합니다.
2. GitHub 저장소 페이지의 **Settings > Pages** 메뉴로 이동합니다.
3. **Build and deployment > Branch** 항목에서 `main` (또는 `master`) 브랜치와 `/(root)` 디렉토리를 선택하고 **Save**를 클릭합니다.
4. 1~2분 후 생성되는 `https://<github-username>.github.io/smart-learning/` URL을 통해 PC, 태블릿, 스마트폰에서 즉시 접속할 수 있습니다.

## 🛠 향후 신규 콘텐츠 추가 가이드 (확장 방법)

새로운 모의고사, 퀴즈, 실습 콘텐츠를 추가할 때 기존 코드를 수정할 필요 없이 손쉽게 확장할 수 있습니다.

### 예시 1: 새 모의고사 추가 시
1. `exams/신규시험-cbt/` 디렉토리를 생성하고 `index.html`, `style.css`, `questions.js`, `app.js`를 작성합니다.
2. 메인 `index.html`의 `#exams` 섹션에 새 카드를 추가하고 링크를 `./exams/신규시험-cbt/index.html`로 연결합니다.

### 예시 2: 새 단원별 OX 퀴즈 추가 시
1. `quizzes/com1-ox/` 디렉토리를 생성하고 퀴즈 페이지를 작성합니다.
2. 메인 `index.html`의 `#quizzes` 섹션에 해당 카드 링크를 연결합니다.
